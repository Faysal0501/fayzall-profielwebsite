# Fayzall profielwebsite

Deze map kun je rechtstreeks openen in Visual Studio Code.

## Openen in Visual Studio Code

1. Pak het zipbestand uit.
2. Open Visual Studio Code.
3. Kies `File` → `Open Folder`.
4. Selecteer de map `fayzall-profielwebsite`.
5. Open `index.html`.
6. Installeer eventueel de VS Code-extensie **Live Server**.
7. Klik rechtsonder op **Go Live** om de website lokaal te bekijken.

Zonder Live Server kun je ook dubbelklikken op `index.html`.

## Bestanden

- `index.html`: alle teksten en de indeling van de pagina.
- `style.css`: kleuren, vormgeving en mobiele weergave.
- `script.js`: laat de rekenmachine werken en vult automatisch het juiste jaartal in.
- `images/mbo-verklaring.jpg`: foto van de mbo-verklaring.

## Uploaden naar je eigen server

Upload `index.html`, `style.css`, `script.js` én de map `images` naar de openbare webmap van je hostingpakket. Die map heet vaak `public_html`, `www` of `htdocs`. Zorg dat de drie bestanden en de map `images` naast elkaar staan.

Voorbeelden:

- cPanel: open **File Manager** → `public_html` → upload de drie bestanden.
- Plesk: open **Files** → `httpdocs` → upload de drie bestanden.
- FTP: verbind met FileZilla en upload de bestanden naar de openbare webmap.

## Korte uitleg voor een gesprek

“De inhoud en structuur staan in HTML. In CSS heb ik de kleuren, knoppen, ruimtes en mobiele weergave gemaakt. Met JavaScript houdt de rekenmachine de ingevoerde cijfers en gekozen bewerking bij. Daarna berekent JavaScript de uitkomst. Ik heb ook media queries gebruikt zodat alles op een telefoon werkt.”

Pas de teksten gerust zelf aan. Zorg vooral dat je kunt uitleggen wat ieder bestand doet; dan voelt de website ook echt als jouw eigen werk.
